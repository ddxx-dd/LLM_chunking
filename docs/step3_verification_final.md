# 3단계 검증 마무리 - [1][2][3] 진단·수정 결과 (2026-09-26)

> `docs/step3_rescan_final_report.md`(2차 재스캔)에서 남은 두 문제(pdf 원문 보존율
> 73.5%, docx 잔여 불일치 20건)의 실제 원인을 진단하고 필요한 만큼만 고친 결과.

## [1] pdf 원문 보존율 73.5% — 실제 손상 아님, 측정 방법의 한계로 확인됨

(c) 실패 요소마다 **원본 pdf에서도 같은 방식**(단어 중심점 추출 + normalize_text 비교)으로
재추출해서 비교:

| 판정 | 건수 | 의미 |
|---|---:|---|
| 실제 손상(원본은 일치, 결과는 불일치) | **1 / 31 (3.2%)** | 우리 redaction이 이웃 요소를 지운 경우 |
| 측정 오류(원본도 이미 불일치) | **30 / 31 (96.8%)** | Docling bbox 부정확 자체의 문제, 우리 탓 아님 |

샘플 5개 문서(`2401.06326v4`, `2408.06427v2`, `2403.03367v4`, `2407.02507v2`,
`2408.09344v2`) 전체에서 실제 손상은 `2408.06427v2.pdf` 단 1건뿐 — 인접한 두 저자
소속 정보 블록의 bbox가 겹친 경우였다. **결론: writer는 고치지 않았다** — 지시하신
"실제 손상이 의미 있게 나오면 고쳐라" 기준에 못 미침(3.2%는 유의미한 손상이 아님).
원문 보존율 73.5%라는 낮은 수치는 **검증 스크립트가 Docling bbox 부정확을 그대로
반영해서 나오는 것**이지, 실제 병합 품질 문제가 아니다.

## [2] docx 잔여 불일치 20건 — 원인 확정 및 완전 해결

5개 문서(`MezzoMedia`, `PRP008`, `2022누56595`, `journal-31-3-308`, `제4차_24_28`)에서
원본-결과 diff를 직접 뽑아보니 **5개 전부 정확히 같은 패턴**: 순수 삭제(다른 유형 없음 -
탭/줄바꿈 정규화, 체크박스·기호, 수식, auto_num은 전혀 해당 없었음).

**원인(실측 확정)**: 세로 병합 셀(vMerge)의 연속 행 문단은 OOXML 스펙상 문단은
있지만 **run이 하나도 없는 빈 문단**인 경우가 흔하다(예: "캐나다" 셀의 3개 문단 중
1·2번째는 완전히 빈 문단, 3번째에 실제 텍스트). writer가 "첫 문단에 쓰고 나머진 비움"
규칙을 적용할 때, **첫 문단(paraIds[0])이 바로 이 빈 문단이면** 쓸 `w:t`가 없어서
조용히 실패하는데, **같은 요소의 나머지 문단(실제 텍스트가 있던 paraIds[2])은 그대로
비워버려서** — 결과적으로 아무 데도 안 써진 채 원본 텍스트만 사라지는 실제 데이터
손실이었다. Docling이 못 잡은 문단 가설(말씀하신 대로)은 틀렸고, **보충 처리 조건
문제도 아니라 writer 자체의 버그**였다.

**해결**: `docx_track/writer.py`에 `_append_text_run()` 추가 - 쓸 `w:t`가 없는
문단에는 새 `w:r`/`w:t`를 만들어서 쓴다. 5개 문서 재검증 결과 **전부 완전 일치**로
전환됨.

## [3] docx 통과 기준 비율화 — 완료

**구조 보존 100% + 미기록(unwritten) 0 + 텍스트 일치율 ≥99.5%**로 전환

## 최종 재스캔 결과 (docx만 재실행 - pdf는 [1]에서 수정 없음으로 결론나서 2차 결과 그대로 유효)

| 트랙 | 통과 | 비고 |
|---|---|---|
| **docx** | **45 / 45 (100%)** | writer 버그 수정 후 전체 재스캔, 6.8분(캐시 재사용) |
| pdf | 9 / 50 (18%, 2차 스캔과 동일) | [1] 진단 결과 수정 불필요로 확인, 재실행 안 함 - `docs/step3_rescan_final_report.md`의 pdf 결과가 최종값 |

docx는 이제 **완전한 항등 테스트 통과** 상태 - 45개 문서 전부 구조 보존 100%, 미기록
0건, 텍스트 일치율 99.5% 이상(대부분 100%)을 달성했다. pdf는 비율 기준 자체가 엄격하고
(c) 지표가 측정 방법의 한계를 크게 반영하는 걸 확인했으므로, **낮은 pdf 통과 수(9/50)는
실제 병합 품질 문제라기보다 검증 기준의 엄격함과 측정 한계가 크다**고 결론짓는다(넣기
성공률 95.8%, 그림·도형 보존 100%는 이미 확보됨).
