## docx 45개 결과

| 지표 | 값 |
|---|---|
| 통과 | **25 / 45 (56%)** |
| unwritten(설명 안 되는 미기록) | **45개 문서 전부 0건** (1차 스캔 대비 최대 890건→0, 완전 해결) |
| 구조 보존(w:p/w:drawing/w:pict) | 45개 전부 True |
| 총 소요 시간 | **6.6분**(파싱 2.2 + 항등 0.8 + 표시 3.2 + 병합지표 0.3, 캐시 재사용 덕분에 1차 스캔보다 훨씬 빠름) |

**통과 수 자체는 1차 스캔(25/45)과 동일**하지만 원인이 완전히 다르다 — 1차 실패는 대부분
"문서 상당 부분이 아예 안 써짐"(수백 건 unwritten)이었고, 이번 실패 20건은 **전부
unwritten 0건**, 즉 큰 손실은 없고 문서당 수십 자 단위의 작은 잔여 불일치만 남음(예:
"동일인및관련자" 같은 반복 라벨 몇 개, `2022누56595` 사례처럼 문서 안에서 같은 문구가
여러 도형에 중복 존재하는데 Docling이 그중 일부만 캡처하는 잔여 케이스 - 소스에서 확인한
`_handle_textbox_content()`의 텍스트-내용 기준 중복 제거가 원인으로 추정, `docs/
writer_implementation_review.md` 참고). **병합 결과물의 손실 규모는 1차 대비 극적으로
줄었지만, "완전 일치"라는 엄격한 항등 테스트 기준 자체를 만족하려면 이 잔여 소규모
불일치까지 잡아야 함**.

## pdf 50개 결과 — 비율 기준

| 지표 | 값 |
|---|---|
| **3개 기준 모두 통과** | **9 / 50 (18%)** |
| (a) 텍스트 일치율 ≥99% 통과 문서 | 34 / 50 |
| (b) 그림·도형 보존 100% 통과 문서 | **50 / 50 (전부)** |
| (c) 안 쓴 요소 원문 보존율 ≥99% 통과 문서 | 14 / 50 |
| 넣기 성공률 ≥90%(참고, 통과 기준 아님) | 44 / 50 |
| **전체 넣기 성공률(15,277건 중)** | **95.8%** (1차 스캔 62% → 대폭 개선) |
| ┗ 표 셀 성공률 | 96.5% (3,416건 중) |
| ┗ 본문 요소 성공률 | 95.6% (11,861건 중) |
| 평균 텍스트 일치율 | 98.9% |
| 평균 원문 보존율 | 73.5%(중앙값 91.8%) |
| 총 소요 시간 | **48분**(파싱 8.5 + 항등 39.5) |

### (c) 원문 보존율이 병목인 이유 — 실측 확인

문서별 편차가 크다: 22/50이 ≥95%, 27/50이 ≥90%지만 평균은 73.5%까지 떨어진다 —
**분모(안 쓴 요소 수)가 아주 작은 문서에서 몇 건만 어긋나도 비율이 0%까지 떨어지는
통계적 함정** 때문(예: `2403.03367v4.pdf`는 불일치 딱 2건인데 그게 전부라 0.0%). 실제
내용 손상이 심각하다는 뜻이 아니라 **기준 임계값(99%)이 작은 문서엔 너무 엄격**하다는
뜻에 가깝다 — 임계값을 90%로 낮추면 14/50 → 27/50으로 거의 2배가 된다.

### 개선 효과 요약 (1차 → 2차)
샘플 문서(`2401.06326v4.pdf`) 기준: 넣기 성공률 62%→98.3%, 텍스트 불일치 22건→5건,
원문 보존 불일치 16건→8건. 전체 코퍼스로 확장해도 같은 방향으로 크게 개선됐다(넣기
성공률 62%→95.8%).

## 아직 남은 한계 (실측 확인, 기록만)

1. **docx 소규모 잔여 불일치(20개 문서, 문서당 수십 자)**: Docling 자체의 텍스트-내용
   기준 중복 제거(`processed_paragraphs`, 소스 확인)로 추정 — 완전히 없애려면 Docling
   내부 로직까지 손대야 해서 스트레치 골로 분류.
2. **pdf (a)/(c) 일부 문서에서 인접 요소 bbox가 겹쳐서 텍스트가 섞임**: Docling이 매긴
   bbox 자체가 최대 7pt 정도 겹치는 경우가 있어 단어-중심점 방식으로도 완전히는 못 피함.
3. **pdf (c) 통계적 함정**: 분모가 작은 문서는 소수의 불일치로도 비율이 급락 — 임계값
   해석 시 문서 규모를 같이 봐야 함.
4. **넣기 실패 4.2%(15,277건 중 643건)**: 여전히 일부 존재 — 원인 세분화는 안 함(스트레치 골).
